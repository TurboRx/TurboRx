## 👋 About Me

I'm a self-taught developer focused on **AI/ML** and **cybersecurity**. On the security side I work on **offensive security**: **reverse engineering** binaries to understand how software behaves, and **bug hunting** to find issues that others miss.

I have no formal courses behind me. Everything I know comes from building, breaking, and digging until it clicked.
